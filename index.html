Channel Foundry

A private publishing tool for YouTube channels run by a single operator.

Channel Foundry is not a public service. It has no sign-up, no accounts, and no users other than the person who installed it. It exists to do one job: take video files that the operator has produced and place them on YouTube channels that the same operator owns and controls.

What it does

  • Uploads finished video files to the operator's own YouTube channels.
  • Sets the title, description, tags and thumbnail that the operator has prepared.
  • Uploads caption files that the operator has prepared.
  • Reads back the uploaded video's own status so the operator can confirm it landed.

It talks to YouTube through the YouTube Data API v3. It does not read other people's channels, comments, subscribers or messages, and it never acts on behalf of anyone but the operator who authorised it.

Authorisation

Access is granted by the channel owner through Google's standard OAuth consent flow. The resulting token is stored on the operator's own machine and can be revoked at any time from the Google account's permissions page.
