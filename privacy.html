Privacy Policy

Channel Foundry · last updated 21 September 2026

Channel Foundry is a private publishing tool used by a single operator to upload that operator's own videos to that operator's own YouTube channels. It is not offered to the public; there is nothing for a third party to sign up for and no third party's data is collected. This policy explains exactly what the tool touches.

Use of YouTube API Services

Channel Foundry uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

  • The operator's own channel data, read and written through the YouTube Data API: video files being uploaded, their title, description, tags, privacy status, and the returned video and channel identifiers used to confirm the upload.
  • Caption files the operator has prepared for those same videos.
  • Thumbnail images the operator has prepared for those same videos.

No other channel is read. Comments, subscriptions, playlists, viewers, analytics and personal information of any other person are never requested and never accessed.

How data is stored

The tool runs on the operator's own machine. The videos and metadata stay in the operator's own folders on that machine. The only credential stored is the OAuth refresh token, kept in a local file readable only by that machine's user account, used for no purpose other than uploading to the channels it was granted for.

What is not done with data

  • Nothing is sold, rented or shared with any third party.
  • Nothing is used for advertising or profiling.
  • Nothing is transferred anywhere except to the YouTube API in order to perform the upload the operator asked for.
  • This website sets no cookies and runs no analytics. It is static text served by GitHub Pages, whose own infrastructure may log requests as described in GitHub's privacy statement.

Deleting data and revoking access

Access can be revoked at any time from the Google account's permissions page, which immediately stops the tool from acting on those channels. The stored token can be deleted from the operator's machine at any time, and any uploaded video can be removed from YouTube in the usual way.
